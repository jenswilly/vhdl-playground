# VHDL Playground

This project contains several subprojects for testing VHDL in Vivado.

### Create Project

In subdirectories, first source the Vivado settings script, then run `source init.sh` to create the Vivado project.

### Open Project

If the project's Vivado files have been created, run `source open.sh` to open Vivado and open the project.

### Clean

To clean all Vivado-generated files, run `source clean.sh`. After this, it should be possible to re-create 
the project.
