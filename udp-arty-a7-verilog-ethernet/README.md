# UDP Example for Arty A7

This example uses [verilog-ethernet by Alex Forencich](https://github.com/alexforencich/verilog-ethernet) to create a UDP client.

It is based on the code in `example/Arty/fpga` and uses the verilog-ethernet components as a submodule.

## Tasks

* Add source files from library example (including top)
* Add constraints TCL files from example
* Add own top file (overwrite example)
